Metode Transaksi
Tersedia 4 metode transaksi. Semua metode menghasilkan response yang sama — perbedaan hanya di cara kirim request.

Metode	Endpoint	Sign	Ket
Atrilinks	/h2h/trx/atrilinks	BLAKE3	Paling aman
Otomax	/h2h/trx/otomax	SHA1	Kompatibel Otomax
Query	/h2h/trx/query	—	Simple GET
JSON	/h2h/trx/json	—	POST JSON
Metode Atrilinks direkomendasikan. Metode Query & JSON hanya mengandalkan IP whitelist.

Catatan: response Atrilinks punya field status string (success/pending/failed) dan info — TIDAK ada rc atau status 0/1/2 Digiflazz. Mapping ke rc/status Digiflazz dilakukan di addon.

=== Addon vendor Digiflazz (proyek ini) ===
Metode: **Query** — GET /h2h/trx/query + pin (+ pass opsional). Tanpa BLAKE3/sign (tidak akses panel).
Wajib kirim **urlcallback** = URL publik addon (notifikasi status dari Atrilinks → addon).
Addon wajib expose endpoint HTTP untuk menerima callback; lalu update DB dan webhook ke Digiflazz jika status final.
Keamanan Query: IP whitelist di sisi Atrilinks + PIN/pass di .env + HTTPS; jangan log URL yang memuat pin/pass.

Parameter (semua metode)
Param	Wajib	Keterangan
reqid	Ya	Request ID unik dari Anda
userid	Ya	Kode member
kodeproduk	Ya	Kode produk
tujuan	Ya	Nomor HP / ID Pelanggan
jenistrx	Ya	1=Fixed, 2=Open, 3=Inquiry, 4=Payment, 5=Check
urlcallback	Ya	URL callback notifikasi

pin	Query/JSON	PIN (plain)
nominaltrx	jenistrx=2	Nominal top up (open)

Cek Status Hari Ini
Cek status transaksi yang dibuat HARI INI berdasarkan reqid + userid + tujuan.

Bentuk response SAMA PERSIS dengan response transaksi aslinya (jenis fixed/open/payment, status success/pending/failed) sesuai jenis & status transaksi yang dicek. Gunakan Kata Kunci & Regex yang sama seperti di menu Transaksi untuk parsing. Bila transaksi tidak ditemukan, response berupa objek error: status, reqid, userid, tujuan, info.

Format Atrilinks / Otomax (tidak dipakai addon vendor)
/h2h/trx/atrilinks (BLAKE3) dan /h2h/trx/otomax (SHA1) — butuh sign dari panel.
BLAKE3: combined = "{reqid}|{kodeproduk}|{tujuan}:{userid}:{encryptedPass}:{encryptedPin}:Atrilinks", sign = BLAKE3(combined).hex()
Addon memakai Query saja; urlcallback tetap wajib di setiap order.
